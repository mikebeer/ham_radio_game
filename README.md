# CQ Quest – become a ham radio operator

A 2D learning game for Godot 4.6 (GL Compatibility) that takes a curious newcomer from
"what is ham radio?" to their first QSO. English and German, with legal content for
Germany, Austria, Switzerland, the USA and the UK.

**Flow:** splash → short intro → pick an avatar, name, country and language → radio-shack hub.

**Four goals** (driven by the quest system from [mikebeer/galene](https://github.com/mikebeer/galene)):

1. **Know the rules** – lessons and a quiz for your country. Passing unlocks the licence class and your practice callsign.
2. **Build your shack** – eight parts (power supply, antenna, transceiver, microphone, speaker, SWR meter, Morse key, logbook). Each part has a short technical lesson and a quiz; passing puts the part into your shack.
3. **First contact** – a guided QSO: tune in, answer a CQ call, exchange reports, spell your callsign with the phonetic alphabet, say 73. Needs the rules plus transceiver, antenna, microphone and power supply.
4. **Morse** – Koch method, 10 levels (4 to 40 characters). Listen and pick, or send it yourself with the key (mouse or SPACE).

Everything is drawn in code (`_draw()`), and all sound (UI and Morse) is synthesised, so there are no image or audio assets. Design: Figma file `1c1h1KXR4hK73PNQzxM762`; the Godot layouts use the same 1280×720 coordinates.

## Run

Open the folder with Godot 4.6 and press F5. Progress is saved to `user://cq_quest_save.json`.

Headless checks:

```
godot --headless --path . --import                       # first time, creates font imports
godot --headless --path . --script tools/smoke.gd        # every screen builds, all packs load
godot --headless --path . --script tests/flow.gd         # plays QSO and Morse logic
xvfb-run -a godot --path . --rendering-driver opengl3 --script tools/shots.gd   # screenshots
```

## Content

Content lives in `content/` as JSON (`{"en": ..., "de": ...}` per string) and is generated by
`python3 tools/build_content.py`. The German question pool is read from a local clone of
[DARC-e-V/50ohm-contents-dl](https://github.com/DARC-e-V/50ohm-contents-dl) (path at the top of the script).

| Content | Source | Licence |
|---|---|---|
| DE lessons | 50ohm.de, DARC e.V. | CC BY 4.0 |
| DE questions | Bundesnetzagentur question catalogue, 3rd ed. March 2024 | DL-DE-BY-2.0 |
| AT questions/terms | BMVIT amateur radio question catalogue (2009), supplied by the project owner | check before publishing |
| US, UK, CH, other lessons | original short primers | this project |
| Technical lessons, QSO scripts, UI text | original | this project |

Caveats:
* The English text of the official German questions is an **unofficial translation**; the game says so.
* US, UK and CH packs are **primers, not exam pools**. The Austrian catalogue is from 2009 (open questions, no answers), so the Austrian pack teaches abbreviations and Q-codes and points to the current rules. Always check the regulator's current rules.
* The practice callsigns are placeholders, not real assignments.

## Adding a language or country

* Language: add a code to `I18n.LOCALES`, add the translation to every `{"en", "de"}` entry (`tools/build_content.py`), regenerate.
* Country: add a `xx_pack()` in `tools/build_content.py`, list it in `Content.COUNTRIES` and the setup screen.

## Export

Add `*.json,*.cfg` to "Filters to export non-resource files" in each export preset, otherwise the content and quest files are left out.

## Layout

```
autoloads/   FactDatabase + QuestSystem (from galene), Game state, I18n, Content, Sfx, Style, SceneManager
resources/   quests_cfg/ham.cfg (chapter, quests, tasks)
scripts/ui/  one script per screen, Screen base class, Quiz, ArtView/GearView
scripts/art/ Palette and vector drawing (avatars, shack equipment)
scenes/      thin .tscn files that attach the screen scripts
```
